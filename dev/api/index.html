API

Everything the GUI does with songs can also be done from a script. The exported functions below are the public API; names that are not exported (except DrumMachine.run) are internal and may change in a minor release.

using DrumMachine

song = preset("Rock: 8tel")
song.bpm = 92
song.patterns[2] = make_fill(song.patterns[1], song.steps_per_beat, 2)
song.chain = [1, 1, 1, 2]
save_song("rock92.toml", song)

entry = only(filter(e -> e.name == "BlackPearl", kit_entries()))   # included in the package
kit = get_kit(entry)
export_wav("rock92.wav", song, kit; repeats = 4)

Starting the program

DrumMachine — Module
DrumMachine

Step sequencer for drum practice: enter a groove, preview it, export it as WAV.

using DrumMachine
DrumMachine.run()                 # start the GUI
song = preset("Rock: 8tel")
export_wav("rock.wav", song, first(available_kits()))
DrumMachine.run — Function
run(; song = nothing, block = true)

Starts the drum machine. Without song it continues with the song and state of the last session (see load_session), on the very first start with the preset "Rock: 8tel". block=false returns immediately (for the REPL) and returns (fig, eng).

Songs and patterns

DrumMachine.Song — Type
Song(; name, bpm = 100, swing = nothing, swing_on = 0, steps_per_beat = 4,
     patterns = [Pattern(16)], chain = [1], kit = "CrocellKit", fx = "Clean", fxmix = 0.25,
     master = 0.8, repeats = 8, countin = 1, click = false, mono = false, swap_lr = false,
     loop = false, orn = OrnTuning())

A song: its patterns, the order in which they are played (chain, pattern numbers), tempo, grid (steps_per_beat: 2 = 8ths, 3 = 8th triplets, 4 = 16ths, 6 = 16th triplets, 8 = 32nds), swing (0.5 = straight, 2/3 = triplet, 0.75 = dotted; swing_on 0 = auto, 8 or 16), kit name, room effect and the export settings (repeats of the chain, count-in bars, click, mono, loop). tracks holds one TrackParams per track. Saved and loaded with save_song and load_song; the file format is described on the page Song format.

DrumMachine.Pattern — Type
Pattern(steps = 16)

One bar: a grid of 11 tracks × up to 32 steps. grid[t, s] is the level of the hit on track t at step s (0 = off, 1 = ghost note, 2 = normal, 3 = accent), orn[t, s] its ornament (0 = none, 1 = double stroke, 2 = buzz roll, 3 = flam, 4 = drag). bpm > 0 gives the pattern its own tempo, 0 uses the song tempo. Usually built with pattern_from_rows.

DrumMachine.TrackParams — Type
TrackParams(; vol = 1, pan = 0, pitch = 0, mute = false, solo = false, eq_low = 0, eq_mid = 0,
            eq_midf = 800, eq_high = 0, mod = 1, mod_mix = 0.5, mod_rate = 0.8, mod_depth = 0.5,
            mod_fb = 0, swap = false)

Mixer settings of one track of a Song: volume as linear factor (0 to 4, the slider shows it in dB), pan offset (-1 to 1), pitch in semitones, mute/solo, 3-band EQ in dB (-12 to +12, mid frequency eq_midf 200 to 6000 Hz), modulation (mod: 1 = off, 2 = chorus, 3 = flanger, with mix, rate in Hz, depth, feedback) and swap (mirror left and right).

DrumMachine.pattern_from_rows — Function

Pattern from Dict(track_id => "x.x."). Length = longest row (or steps).

DrumMachine.row_string — Function
row_string(p::Pattern, t::Int) -> String

Track t of p as text, one character per step: . off, o ghost note, x normal, X accent. The inverse of the rows given to pattern_from_rows.

DrumMachine.parse_chain — Function

Chain from text like "1 1 1 2" or "1x3 2" (= 1 1 1 2).

DrumMachine.save_song — Function
save_song(path, song) -> path

Writes song as a TOML file (see the page Song format), creating missing folders.

DrumMachine.load_song — Function
load_song(path) -> Song

Reads a song from a TOML file written by save_song or by hand. Missing keys get their default values.

DrumMachine.song_seconds — Function

Export length in seconds (without decay; with loop, without count-in).

DrumMachine.import_drum_json — Function
import_drum_json(src; name = "") -> (song, notes)

Converts a Drum-JSON composition (src: file path or JSON text) into a Song. One pattern per bar, identical bars share a pattern. notes lists what could not be taken over (unknown sounds, merged toms, flams …).

Presets and fills

DrumMachine.preset — Function
preset(name) -> Song

A new copy of the built-in groove name (one of PRESET_NAMES, e.g. "Rock: 8tel"). Unknown names raise an error that lists the available ones.

DrumMachine.PRESET_NAMES — Constant

Names of all built-in grooves, in menu order; see preset.

DrumMachine.make_fill — Function
make_fill(p, steps_per_beat, style = 1) -> Pattern

Copy of p whose last beats are replaced by the fill FILL_STYLES[style] (the style is chosen cyclically, so any integer is allowed). The fill span starts on a beat; in a bar with a partial last beat (e.g. 7/8 with 14 steps) it also covers that partial beat.

DrumMachine.FILL_STYLES — Constant

Fill styles: (name, length in beats, generator).

Kits

DrumMachine.Kit — Type

A kit: any number of velocity layers per track (soft -> loud), one or more recordings per layer (round-robin). Plus pan, gain and choke group per track.

DrumMachine.kit_entries — Function
kit_entries(dirs = kit_dirs()) -> Vector{KitEntry}

All kits without loading samples: WAV kits from the kit folders (alphabetical by folder, a folder name appears once; the package's own kits/ wins, a hidden folder of the same name is reported once as a warning), followed by the 808- and 909-style synth kits. Temporary build folders (*.building, *.old) are skipped.

DrumMachine.get_kit — Function
get_kit(e::KitEntry) -> Kit

Loads the kit (once; again only if its kit.toml changed). If the samples cannot be read, the synth kit is returned under the kit's name.

DrumMachine.available_kits — Function
available_kits(dirs = kit_dirs()) -> Vector{Kit}

All kits, loaded (see kit_entries). The basic synth kit only serves as a fallback for missing samples.

DrumMachine.load_kit — Function
load_kit(dir) -> Kit

Load a kit from dir/kit.toml. Each track supports two formats:

  • file = "36-Pearl-22-Kick": files <file>-1.wav ... <file>-N.wav (soft -> loud), or a single <file>.wav (see kits/BlackPearl/kit.toml).
  • folder = "Kick": folder with <layer>-<rr>.wav, e.g. 01-1.wav, 01-2.wav, 02-1.wav ... (layers soft -> loud, several round-robins per layer).

Missing tracks are filled with synthetic sounds.

DrumMachine.synth_kit — Function

Synthetic kit: one layer per track (dynamics via level only).

Rendering and export

DrumMachine.render_song — Function
render_song(song, kit; repeats, countin, click, loop, tail) -> Matrix{Float32}

Renders count-in + repeats × chain offline as a stereo matrix (samples × 2).

loop = true: seamless loop. No count-in, the length matches the chain exactly, and the decay after the last bar (cymbals, reverb) is added to the beginning and the grace notes of a flam or drag on step 1 go to the end – so the file sounds as if played through when looped endlessly, with no gap and no cut-off reverb.

Without loop and without count-in, a flam or drag on step 1 starts the file with a pickup of a 16th before beat 1 (longer for a long flam or drag at a fast tempo), the same as in the MIDI export (see DrumMachine.export_pickup).

tail is the decay in seconds after the last step (silence below -70 dB is trimmed); with the Echo effect it is at least as long as the repeats need (one 8th per repeat).

DrumMachine.export_wav — Function
export_wav(path, song, kit; mono = song.mono, bits = 16, kw...) -> path

Writes the rendered song as a standard WAV (RIFF, PCM, 44.1 kHz, 16 bit like an audio CD): stereo or, with mono = true, single-channel. The file name is converted to pure ASCII with ascii_filename; the path actually written is returned. Other keywords as for render_song.

DrumMachine.export_midi — Function
export_midi(path, song; repeats = song.repeats, countin, click = song.click, loop = song.loop) -> path

Writes the song as a Standard MIDI File (format 0, 960 ticks per quarter, channel 10): the chain repeats times after countin count-in bars (none with loop = true). Notes per track as on the Roland TD-27 and in General MIDI (kick 36, snare 38, side stick 37, hi-hat 42/46/44, toms 48/43, ride 51, bell 53, crash 49), click 33 and 34. Ghost note, normal and accent get velocity 35, 90 and 120. Before each hi-hat note, controller 4 (hi-hat opening, used by Roland modules) is set on the same tick: 127 for closed (42) and pedal (44), 0 for open (46). Swing, pattern tempo (tempo changes), ornaments and mute/solo are included. The file ends after the last bar.

A triplet bar that is not a whole number of 8ths (e.g. 10 or 16 steps at 3 steps per beat) has no exact time signature: the previous one stays in effect, so from that bar on the bar lines in a DAW or notation program are shifted. Pad such patterns to whole beats. With loop = true, grace notes of a flam or drag on step 1 are at the end of the file, as in the loop WAV; without loop and count-in they sit in a pickup bar before bar 1: a 16th (1/16), longer for a long flam or drag at a fast tempo. The WAV export starts with the same pickup, so both files line up at time 0.

DrumMachine.ascii_filename — Function
ascii_filename(name) -> String

File name of ASCII characters only, as required e.g. by drum modules (Roland TD-27): umlauts are spelled out (ä → ae, ß → ss), accents removed (é → e), all other characters except letters, digits, spaces and . _ - ( ) become _.

DrumMachine.Engine — Type
Engine(song, kit)

Playback state of the GUI: the current Song and Kit, the voices, effects and transport. The audio callback calls it block by block; offline rendering (render_song, export_wav) uses its own engine, so scripts normally don't need to create one.

WAV files

DrumMachine.Wave — Type
Wave

Audio being edited: data is samples × channels (Float32, nominally -1…1), fs the sample rate. bits is the bit depth of the source file and the default for saving.

DrumMachine.load_wave — Function
load_wave(path) -> Wave

Loads a WAV file (any PCM/float format WAV.jl can read). The bit depth becomes the default save format: 16 and 24 bit are kept, 8 bit is saved as 16 bit and 32/64 bit as 32-bit float. Files with more than two channels keep the first two (front left/right); the editor works on mono and stereo.

DrumMachine.save_wave — Function
save_wave(path, w; bits = w.bits, range = nothing) -> path

Writes PCM (16/24 bit) or 32-bit float WAV. Samples are clamped to -1…1 for PCM (WAV.jl would otherwise throw on values above full scale). Only fmt and data chunks are written, which is what devices like the Roland TD-27 expect. range saves just that part (e.g. the selection).
