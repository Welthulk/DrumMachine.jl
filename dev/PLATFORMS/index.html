Platforms

DrumMachine is developed and tested on Linux only (KDE Plasma on Wayland, Julia 1.13). Windows and macOS have not been tested. The main building blocks (Julia, GLMakie, PortAudio) exist for all three systems, so the core should run there, but some convenience functions rely on Linux tools. I only test on Linux. If you would like to port DrumMachine to Windows or macOS, you are very welcome: issues and pull requests are appreciated.

Known gaps for a port:

  • Windows: no file dialogs (only zenity/kdialog are supported); the built-in tar.exe is not looked for, so the kits cannot be unpacked; start_drum.sh needs Git Bash or WSL.
  • macOS: zenity and ffmpeg are available via Homebrew; OpenGL is deprecated there but still available. The GC pause ends below 1 GB of free memory, which macOS often reports even when enough RAM is available.
  • start_drum.sh --prio and the realtime audio thread use Linux scheduling (nice, SCHED_FIFO); on other systems the program runs with normal priority.
  • Settings and songs are stored in ~/.config and ~/.local/share (XDG) on every system; the usual places would be %APPDATA% on Windows and ~/Library/Application Support on macOS.
