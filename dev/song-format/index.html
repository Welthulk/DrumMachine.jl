Song file format

A song is a plain TOML file, by default in songs/<name>.toml. Everything the program knows about a song is stored there: tempo, grid, patterns, chain, kit, master effect, the per-track mixer and effects (EQ, chorus, flanger) and the export settings. The files are meant to be read and edited by hand.

All keys are optional. A missing key gets the default listed below, so a minimal song is just:

[[pattern]]
    [pattern.rows]
    HiHat = "x.x.x.x.x.x.x.x."
    Snare = "....X.......X..."
    Kick  = "X.......X.X....."

Comments are lost when saving. You can add # comments when editing a file by hand (the example songs do), but Speichern (save) in the program rewrites the whole file without them.

Song settings (top level)

KeyTypeDefaultMeaning
namestring"Neu"Song name, also used for the file names of save and export
bpmnumber100.0Tempo in beats per minute (GUI range 30–400)
steps_per_beatinteger4Grid: 4 = 16ths, 3 = 8th triplets, 6 = 16th triplets, 2 = 8ths, 8 = 32nds
swingnumber0.5 (2/3 for triplet grids in files without swing_version)Position of the off-beat note within its group: 0.5 straight, 0.667 triplet, 0.75 dotted (used range 0.5–0.8)
swing_oninteger0What swings in a straight grid: 0 auto, 8 8ths, 16 16ths
swing_versioninteger1Written as 2 by current versions. Files without it that use a triplet grid and swing = 0.5 are read as exact triplets (compatibility with v0.1)
chainarray of integers[1]Pattern order for song mode and export, 1-based. Invalid numbers are dropped
kitstring"CrocellKit"Kit name: a folder in kits/ (e.g. BlackPearl) or 808 (Synth) / 909 (Synth). If the kit is not installed, the program keeps the current kit
fxstring"Clean"Master effect: Clean, Room, Hall, Echo, Drive, Lo-Fi
fxmixnumber0.25Amount of the master effect, 0–1
masternumber0.8Master volume, 0–1.5 (soft limiter after it)

Export settings

KeyTypeDefaultMeaning
repeatsinteger8How often the chain is written into the WAV
countininteger1Count-in bars before the song (ignored with loop)
clickbooleanfalseMix a metronome click into the export
monobooleanfalseMono output (playback and export)
swap_lrbooleanfalseSwap left and right channel (playback and export)
loopbooleanfalseSeamless loop export: no count-in, exactly whole bars, decay folded onto the start

Patterns

Each [[pattern]] table is one pattern; their order gives the pattern numbers 1, 2, 3, … used in chain. Up to 24 patterns can be edited in the program.

[[pattern]]
steps = 16
    [pattern.rows]
    HiHat  = "x.x.x.x.x.x.x..."
    HHOpen = "..............X."
    Snare  = ".o..X..o.o..X..o"
    Kick   = "X..x..x..x....x."
KeyTypeDefaultMeaning
stepsinteger16Length of the pattern in steps, 1–32. Patterns of one song may differ (e.g. 8 steps for a 2/4 bar in a 4/4 song)
rowstableemptyOne string per track, one character per step
orntableemptyOrnaments: one string per track, one character per step (see below)
bpmnumber–Own tempo of this pattern (30–400). Without it the pattern plays at the song tempo bpm. Written only when set; the count-in uses the tempo of the first pattern of the chain

Characters in a row:

CharacterLevel
. (also -, _, space)off
oghost note
x (also *)normal
X (also #)accent

Rows of tracks without any note are left out when saving. A row longer than steps is cut off, a shorter one is filled with rests.

Ornaments

The optional orn table adds an ornament to a note. Its strings line up with rows; a character only counts where the row has a note.

CharacterOrnament
. (also -, _, space)none
2double stroke: a second stroke on the half step (two 32nds in the 16th grid)
zbuzz roll: soft bounces across the step
fflam: one soft grace note just before the note
rdrag (ruff): two soft grace notes just before the note

A 5-stroke roll in the 16th grid is a double stroke on “3+” and “a” followed by an accent on “4”:

[[pattern]]
steps = 16
    [pattern.rows]
    Snare = "....X.....xxX..."
    [pattern.orn]
    Snare = "..........22...."

Tracks without ornaments are left out of orn when saving; songs without ornaments have no orn table at all.

The timing of the ornaments is set per song in the optional top-level table [ornaments] (in the program: Verzierungen on the right). Only values that differ from the defaults are saved.

KeyDefaultRangeMeaning
flam_ms3010–80Flam: grace note this many ms before the note
drag_ms4515–80Drag: distance between its strokes; grace notes 2× and 1× this distance before the note
buzz_ms168–40Buzz roll: distance of the bounces (4–16 strokes per step)
grace1.00.2–1.5Volume of the flam and drag grace notes (factor)

In fast grids the grace notes are moved closer together evenly so that they fit before the note.

[ornaments]
flam_ms = 25.0
grace = 0.8

Unknown track names are ignored: in pattern rows with a warning, [track.<name>] tables silently.

Tracks: mixer and effects

Each [track.<name>] table holds the mixer settings and effects of one track (names as above). The program writes a table for every track. EQ and modulation keys appear only when the effect is active, so a track without effects looks like this:

[track.Snare]
vol = 1.0
pan = 0.0
pitch = 0.0
mute = false
solo = false
KeyTypeDefaultMeaning
volnumber1.0Volume as linear factor, 0–4 (the slider shows it in dB: off, −30 … +12 dB; 1.0 = 0 dB, 2.0 ≈ +6 dB)
pannumber0.0Panorama offset from the kit's own panning, -1 (left) … 1 (right)
pitchnumber0.0Tuning in semitones
mutebooleanfalseMuted (also in the export)
solobooleanfalseSolo (also in the export)
swap_lrbooleanfalseMirror the track left/right (stereo samples: channels swapped); written only when true

EQ

Three bands per track. The EQ is active as soon as one gain is not 0.

KeyTypeDefaultMeaning
eq_lownumber0.0Low shelf at 120 Hz, in dB (-12 … +12)
eq_midnumber0.0Mid bell, in dB (-12 … +12)
eq_mid_freqnumber800.0Frequency of the mid bell in Hz (200–6000)
eq_highnumber0.0High shelf at 5 kHz, in dB (-12 … +12)

Chorus / flanger

KeyTypeDefaultMeaning
modstring"Aus"Aus (off), Chorus or Flanger. The value names follow the German GUI
mod_mixnumberChorus 0.8, Flanger 1.0Effect amount, 0–1 (1 = equal dry and wet)
mod_ratenumberChorus 0.8, Flanger 0.3LFO speed in Hz
mod_depthnumberChorus 0.8, Flanger 0.9Modulation depth, 0–1
mod_feedbacknumberChorus 0.0, Flanger 0.75Feedback, 0–0.9 (higher = more metallic)

When mod is set, the defaults of that effect apply to every mod_* key that is missing.

Example: flanger on the crash and a scooped bass drum.

[track.Crash]
vol = 0.85
pan = -0.2
mod = "Flanger"
mod_mix = 1.0
mod_rate = 0.15
mod_depth = 1.0
mod_feedback = 0.8

[track.Kick]
eq_low = 5.0
eq_mid = -6.0
eq_mid_freq = 400.0
eq_high = 5.0

Complete example

The files in songs/ are complete, commented examples. A short one:

name = "Two Bar Groove"
bpm = 96.0
steps_per_beat = 4
swing = 0.5
chain = [1, 1, 1, 2]
kit = "BlackPearl"
fx = "Room"
fxmix = 0.3
master = 0.8
repeats = 4
countin = 1
loop = false

[[pattern]]
steps = 16
    [pattern.rows]
    HiHat = "x.x.x.x.x.x.x.x."
    Snare = "....X..o....X..."
    Kick  = "X.......X.X....."

[[pattern]]
steps = 16
    [pattern.rows]
    HiHat    = "x.x.x.x.x.x....."
    Snare    = "....X..o....Xxx."
    FloorTom = "...............X"
    Kick     = "X.......X.X....X"

[track.HiHat]
vol = 0.9
pan = 0.15
